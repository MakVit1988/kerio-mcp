# История изменений

## 1.0.2

- Установщик находит `claude_desktop_config.json` в любых папках Claude, в том числе в `AppData\Local\Claude-Data\…`
  (версия из Microsoft Store), и обновляет все найденные копии, не трогая остальные настройки.
- `install.bat` понимает запуск из исходников и подсказывает, какой файл скачать, если запущен не из пакета.
- Удаление больше не падает с `EPERM`: `uninstall.bat` выходит из папки установки, удаление повторяется, а при
  неудаче программа объясняет, что делать; недоудалённую установку можно удалить повторно.
- Сервер читает `.env` не только из текущей папки, но и из папки с `server.js`.
- Версия сервера берётся из `package.json`.
- Описание переписано, добавлены `CHANGELOG.md` и `SECURITY.md`.

## 1.0.1

- Календарь и собрания: `list-events`, `read-event`, `create-event`, `update-event`, `delete-event`,
  `list-invitations`, `respond-to-invitation`, `check-availability`, `find-meeting-time`.

## 1.0.0

- Почта: чтение, поиск, отправка, черновики, флажки, перенос, удаление, папки.
- Вложения: скачивание и отправка из выбранной папки файлов.
- Установщик для Windows (Claude Desktop и Claude Code), публикация через GitHub Releases.

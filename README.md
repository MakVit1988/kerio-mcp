# kerio-mcp

MCP-сервер для почтового ящика на **Kerio Connect**. Работает через HTTPS JSON-RPC API веб-клиента
(`https://<хост>/webmail/api/jsonrpc/`), то есть нужен только порт 443. Поэтому он работает и на
обычном компьютере, и в облачных сессиях, где IMAP (порт 993) и SMTP (465/587) закрыты.

## Инструменты

| Инструмент | Что делает |
|---|---|
| `list-folders` | список папок |
| `list-emails` | последние письма папки (`inbox`, `sent`, `drafts`, `trash`, `junk` или имя папки); `unreadOnly` — только непрочитанные |
| `search-emails` | поиск по теме и отправителю |
| `read-email` | читает письмо: заголовки, текст (HTML очищается, скрытый текст удаляется), имена вложений |
| `send-email` | отправляет письмо (текст, без вложений) |
| `draft-email` | сохраняет письмо в «Черновики» |
| `mark-as-read` | отметить прочитанным / непрочитанным |
| `flag-email` | поставить или снять флажок (по умолчанию красный) |
| `move-emails` | перенести письма в другую папку (у перенесённых писем новые id) |
| `delete-email` | в «Удалённые»; `permanent: true` — удалить совсем |
| `create-folder` | создать папку |

Не поддерживается: вложения при отправке и чтение вложений, календарь и контакты, удаление папок
(API не принимает известные параметры).

## Что нужно заранее

- **Node.js 18 или новее** (проверка: `node -v`) и **git**.
- Адрес веб-клиента Kerio (тот, который вы открываете в браузере для WebMail), например `mail.example.com`.
  У сертификата сервера должно совпадать это имя.
- Полный адрес ящика и пароль (если включена двухфакторная защита — пароль приложения).

## Установка (один раз)

```bash
git clone https://github.com/MakVit1988/kerio-mcp
cd kerio-mcp
npm install
npm test
```

Запомните полный путь к папке, он понадобится ниже: `pwd` (macOS, Linux) или `cd` (Windows).

## Использование в обычной сессии (на вашем компьютере)

Три переменные окружения, которые нужны серверу:

| Переменная | Значение |
|---|---|
| `KERIO_HOST` | хост веб-клиента, например `mail.example.com` (без `https://`) |
| `KERIO_USER` | полный адрес ящика, например `you@example.com` |
| `KERIO_PASSWORD` | пароль |

### Вариант 1. Claude Desktop

1. Откройте файл настроек (если его нет, создайте):
   - macOS: `~/Library/Application Support/Claude/claude_desktop_config.json`
   - Windows: `%APPDATA%\Claude\claude_desktop_config.json`
   (или в приложении: Settings → Developer → Edit Config).
2. Добавьте сервер (пути на Windows пишите с двойными обратными слэшами, `C:\\Users\\...\\kerio-mcp\\server.js`):

   ```json
   {
     "mcpServers": {
       "kerio-mail": {
         "command": "node",
         "args": ["/полный/путь/к/kerio-mcp/server.js"],
         "env": {
           "KERIO_HOST": "mail.example.com",
           "KERIO_USER": "you@example.com",
           "KERIO_PASSWORD": "ваш-пароль"
         }
       }
     }
   }
   ```
3. **Полностью закройте и снова откройте Claude Desktop** (не просто окно).
4. В новом чате должен появиться значок инструментов с `kerio-mail`. Проверьте: «покажи последние 5 писем во входящих».

### Вариант 2. Claude Code в терминале на вашем компьютере

Одной командой (сервер будет доступен во всех ваших проектах):

```bash
claude mcp add kerio-mail --scope user \
  --env KERIO_HOST=mail.example.com \
  --env KERIO_USER=you@example.com \
  --env KERIO_PASSWORD='ваш-пароль' \
  -- node /полный/путь/к/kerio-mcp/server.js
```

Проверка: `claude mcp list` (сервер `kerio-mail` должен быть в состоянии Connected), затем в сессии `claude`
спросите: «покажи непрочитанные письма».

Либо без пароля в командной строке: положите `KERIO_HOST`, `KERIO_USER`, `KERIO_PASSWORD` в файл `.env`
в папке `kerio-mcp` (образец `.env.example`), и сервер сам их прочитает:

```bash
cp .env.example .env     # заполните значения
claude mcp add kerio-mail --scope user -- node /полный/путь/к/kerio-mcp/server.js
```

### Вариант 3. Из папки репозитория

Если запускаете `claude` прямо в папке `kerio-mcp`, файл `.mcp.json` уже регистрирует сервер `kerio-mail`.
Он берёт значения из переменных окружения, поэтому задайте их перед запуском:

```bash
export KERIO_HOST=mail.example.com KERIO_USER=you@example.com KERIO_PASSWORD='ваш-пароль'
claude
```

### Как пользоваться

Просто пишите задачи обычным языком, например:

- «покажи непрочитанные письма за сегодня»
- «найди письма от Иванова про счёт и коротко перескажи»
- «ответь на письмо с id … текстом …» (перед отправкой Claude покажет текст, подтвердите его)
- «пометь прочитанными и красным флажком письма …»

Всё остальное (куда класть письма, что считать важным) решаете вы в запросе. Отправка идёт от имени
вашего ящика, поэтому просите показывать письмо перед отправкой.

### Проверка и поиск проблем

```bash
npm run inspect     # MCP Inspector: список инструментов и пробные вызовы
```

| Симптом | Причина |
|---|---|
| `Kerio login failed` | неверный логин или пароль (или нужен пароль приложения) |
| `Kerio is not reachable` | хост указан неверно или недоступен порт 443; проверьте WebMail в браузере |
| ошибка сертификата | имя в `KERIO_HOST` не совпадает с именем в сертификате сервера |
| Claude не видит инструменты | после правки конфигурации Desktop не перезапущен полностью |

## Использование в облачной сессии

Репозиторий можно подключить к облачной сессии Claude Code. Задайте `KERIO_HOST`, `KERIO_USER`,
`KERIO_PASSWORD` в секретах окружения сессии и откройте репозиторий в ней: файл `.mcp.json`
зарегистрирует сервер. Так как нужен только HTTPS, облачные ограничения на IMAP/SMTP здесь не мешают.

## Безопасность

- **Пароль не хранится в репозитории**: `.env` в `.gitignore`. Не вставляйте пароль в чат.
- Содержимое писем в ответах помечено как данные, а не инструкции. Скрытые элементы HTML
  (`display:none`, `font-size:0` и т. п.) и невидимые символы удаляются.
- Отправка идёт от вашего имени: просите показывать текст письма перед отправкой.

## Как это устроено

- `src/kerio-client.js` — клиент API: вход при первом запросе, повторный вход при «Session expired»,
  повторы при сетевых обрывах, перевод HTML писем в текст без скрытого текста.
- `src/tools.js` — описание инструментов MCP.
- `server.js` — запуск stdio-сервера.

## Особенности API Kerio, найденные при разработке

- Фильтры по `isSeen`/`isFlagged` сервер принимает, но игнорирует: непрочитанные отбираются на стороне
  клиента (просматривается до 1000 последних писем).
- Перенос письма: `Mails.set` с полем `folderId`. Удаление насовсем: `Mails.remove` с `ids`.
- Отправка: создать черновик (`Mails.create`), затем `Mails.set` с `send: true` и полем `from`.
- Вложения требуют предварительной загрузки файла (ID со сроком жизни 60 минут), адрес загрузки не
  найден, поэтому в этой версии вложения не поддерживаются.

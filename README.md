# kerio-mcp

[![Tests](https://github.com/MakVit1988/kerio-mcp/actions/workflows/ci.yml/badge.svg)](https://github.com/MakVit1988/kerio-mcp/actions/workflows/ci.yml)
[![License: MIT](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)

**Почта и календарь Kerio Connect для Claude.** MCP-сервер, который позволяет Claude (Desktop и Code) читать и
отправлять письма, работать с вложениями, вести календарь и назначать собрания в вашем ящике на Kerio Connect.
Установка на Windows: скачать архив, запустить `install.bat`, ввести почту и пароль.

*English: an MCP server that gives Claude access to a Kerio Connect mailbox (mail, attachments, calendar, meetings)
through the web client's HTTPS API. Windows installer on the Releases page; docs below are in Russian.*

## Что умеет

- **Почта:** читать, искать, отправлять, сохранять черновики, отмечать прочитанными, ставить флажки, переносить и удалять.
- **Файлы:** скачивать вложения и отправлять файлы из одной выбранной папки.
- **Календарь:** события и повторы, поиск свободного времени для нескольких людей.
- **Собрания:** приглашения участников, ответы на приглашения, перенос и отмена.

Работает через веб-интерфейс Kerio по HTTPS (порт 443), поэтому подходит там, где IMAP и SMTP закрыты, в том числе в
облачных сессиях. Для **любого** сервера Kerio Connect: адрес сервера вы указываете сами.

> Содержимое писем передаётся Claude как данные, но письмо — это текст от посторонних людей. Отправка писем и
> приглашений идёт **от вашего имени**: просите Claude показывать текст и список участников перед отправкой.
> Подробнее в разделе [«Безопасность»](#безопасность).

## Установка на Windows (самый простой способ)

1. Откройте страницу [Releases](../../releases/latest) и в разделе **Assets** скачайте **`kerio-mcp-installer.zip`**.
   (Не «Source code»: это исходники, а не установщик.)
2. Распакуйте архив целиком и запустите **`install.bat`**. Если Windows пишет «Защитили ваш компьютер», нажмите
   «Подробнее» → «Выполнить в любом случае» (установщик не подписан цифровой подписью).
3. Ответьте на вопросы: адрес почтового сервера (как в браузере для WebMail, например `mail.example.com`), почта, пароль
   (при вводе не отображается), папка установки и папка для файлов.
4. **Полностью закройте Claude Desktop** (значок в трее → Выход) и откройте снова. Для Claude Code достаточно новой сессии.
5. Спросите, например: «покажи непрочитанные письма».

Что делает установщик: проверяет вход в почту, копирует программу и личную копию `node.exe` (Node.js ставить не нужно),
сохраняет пароль в `config.json` (доступ только у вашей учётной записи Windows), прописывает сервер в **Claude Desktop**
(находит файл настроек и в нестандартных папках, остальные настройки не трогает, делает копию) и в **Claude Code**
(`claude mcp add --scope user`, если он установлен).

**Обновление:** скачайте новый архив и запустите `install.bat` ещё раз, закрыв Claude. **Удаление:** `uninstall.bat` в
папке установки (папка с вашими файлами остаётся).

Для администраторов: установка без вопросов `install.bat --yes --email ivan@example.com --host mail.example.com
--install-dir D --files-dir F`, пароль в переменной окружения `KERIO_SETUP_PASSWORD`.

## Установка вручную (macOS, Linux, разработчики)

Нужны **Node.js 18+** и **git**, адрес веб-клиента Kerio (тот, что открывается в браузере для WebMail; имя должно
совпадать с именем в сертификате сервера), полный адрес ящика и пароль (при двухфакторной защите — пароль приложения).

```bash
git clone https://github.com/MakVit1988/kerio-mcp
cd kerio-mcp
npm install
npm test
```

### Настройки

Сервер берёт их из переменных окружения, из файла `.env` в папке программы (образец `.env.example`) или из `config.json`
(его создаёт установщик). Переменные окружения главнее.

| Переменная | Значение |
|---|---|
| `KERIO_HOST` | хост веб-клиента, например `mail.example.com` (без `https://`) |
| `KERIO_USER` | полный адрес ящика |
| `KERIO_PASSWORD` | пароль |
| `KERIO_FILES_DIR` | папка для файлов; по умолчанию `~/kerio-mcp-files` |
| `KERIO_MAX_FILE_MB` | максимальный размер файла, МБ; по умолчанию 25 |
| `KERIO_TIMEZONE_OFFSET` | часовой пояс календаря, например `+03:00`; по умолчанию берётся из ящика |

### Claude Desktop

Откройте **Settings → Developer → Edit Config** (откроется нужный файл `claude_desktop_config.json`) и добавьте сервер.
Пути на Windows пишите с двойными обратными слэшами. Если в файле уже есть другие настройки, блок `mcpServers`
добавляется рядом с ними на верхнем уровне.

```json
{
  "mcpServers": {
    "kerio-mail": {
      "command": "node",
      "args": ["/полный/путь/к/kerio-mcp/server.js"],
      "env": {
        "KERIO_HOST": "mail.example.com",
        "KERIO_USER": "you@example.com",
        "KERIO_PASSWORD": "ваш-пароль"
      }
    }
  }
}
```

Затем полностью закройте Claude (трей → Выход) и откройте снова. В Settings → Developer должен появиться `kerio-mail`.

### Claude Code

```bash
claude mcp add kerio-mail --scope user \
  --env KERIO_HOST=mail.example.com \
  --env KERIO_USER=you@example.com \
  --env KERIO_PASSWORD='ваш-пароль' \
  -- node /полный/путь/к/kerio-mcp/server.js
claude mcp list        # kerio-mail должен быть Connected
```

Если запускаете `claude` прямо в папке репозитория, файл `.mcp.json` уже регистрирует сервер и берёт значения из
переменных окружения. В облачной сессии Claude Code задайте те же три переменные в секретах окружения.

## Возможности и примеры

Просто пишите задачи обычным языком:

- «покажи непрочитанные письма за сегодня», «найди письма от Иванова про счёт и коротко перескажи»
- «скачай вложения из последнего письма от Иванова»
- «отправь письмо на … с темой … и приложи файл КП.pdf»
- «что у меня в календаре на этой неделе», «перенеси встречу на 16:30»
- «найди час на следующей неделе, когда свободны Иванов и Петров, и назначь собрание «Планирование»»
- «какие у меня приглашения? прими приглашение на планёрку»

| Инструмент | Что делает |
|---|---|
| **Почта** | |
| `list-folders` | список папок |
| `list-emails` | последние письма папки (`inbox`, `sent`, `drafts`, `trash`, `junk` или имя); `unreadOnly` — только непрочитанные |
| `search-emails` | поиск по теме и отправителю |
| `read-email` | письмо целиком: заголовки, текст (HTML очищается, скрытый текст удаляется), пронумерованные вложения |
| `send-email` | отправляет письмо (текст); можно прикрепить файлы из папки файлов |
| `draft-email` | сохраняет в «Черновики», тоже с вложениями |
| `mark-as-read` | прочитано / непрочитано |
| `flag-email` | флажок (по умолчанию красный) |
| `move-emails` | перенос в другую папку (у перенесённых писем новые id) |
| `delete-email` | в «Удалённые»; `permanent: true` — насовсем |
| `create-folder` | создать папку |
| **Файлы** | |
| `download-attachment` | скачивает вложения (все или одно — по номеру или имени) в папку файлов |
| `list-files` | что лежит в папке файлов |
| **Календарь и собрания** | |
| `list-events` | события за период (повторяющиеся уже раскрыты), по умолчанию ближайшие 7 дней |
| `read-event` | событие целиком: время, место, описание, участники и их ответы |
| `create-event` | создать событие; с `attendees` это собрание, и Kerio рассылает приглашения |
| `update-event` | изменить (только указанные поля; у повторяющихся — одно, это и следующие или все) |
| `delete-event` | удалить событие или одно повторение |
| `list-invitations` | приглашения, изменения и отмены, ожидающие в календаре |
| `respond-to-invitation` | принять, принять условно или отклонить |
| `check-availability` | когда заняты указанные люди |
| `find-meeting-time` | общее свободное время участников в рабочие часы |

### Файлы

Все файлы, которые сервер читает или пишет, лежат в **одной папке** (`KERIO_FILES_DIR`). Скачанные вложения попадают в
`downloads/<код письма>/` и никогда не перезаписывают существующие файлы. Чтобы отправить файл, положите его в эту
папку (подпапки работают) и назовите его в запросе. Пути вне папки сервер отклоняет, в том числе через `..` и ссылки.

### Календарь и собрания

- Время указывается по часовому поясу ящика, например `2026-10-30T15:00`.
- Занятость видна только у людей с календарём на этом сервере; для остальных адресов Claude скажет, что данных нет.
- Приглашения, изменения и отмены собраний уходят людям от вашего имени: подтверждайте участников и время.

## Безопасность

- **Пароль** хранится только у вас: в `config.json` в папке установки (права только у вашей учётной записи) или в
  `.env`/переменных окружения. В репозитории его нет (`.env` в `.gitignore`). Не вставляйте пароль в чат.
- Программа обращается **только к вашему серверу Kerio** по HTTPS. Никаких других адресов, телеметрии и сторонних сервисов.
- **Письма недоверенные.** Их текст в ответах помечен как данные, скрытые элементы HTML (`display:none`, `font-size:0` и
  т. п.) и невидимые символы удаляются, но Claude читает чужой текст. Поэтому файлы доступны только из одной папки: письмо
  со скрытой инструкцией не сможет заставить отправить ваши ключи или документы из других мест.
- **Отправка идёт от вашего имени.** Просите показывать письма и приглашения перед отправкой.
- Установщик не подписан цифровой подписью, поэтому Windows показывает предупреждение. `node.exe` скачивается с
  nodejs.org с проверкой SHA-256.

О найденной уязвимости сообщайте через [Security advisories](../../security/advisories/new) репозитория, см. [SECURITY.md](SECURITY.md).

## Если что-то не работает

| Симптом | Что делать |
|---|---|
| `Kerio login failed` | неверная почта или пароль (при двухфакторной защите нужен пароль приложения) |
| `Kerio is not reachable` | неверный адрес сервера или недоступен порт 443; проверьте WebMail в браузере |
| ошибка сертификата | имя в `KERIO_HOST` не совпадает с именем в сертификате сервера |
| В Claude Desktop (Settings → Developer) нет `kerio-mail` | полностью перезапустите Claude (трей → Выход). Версия из Microsoft Store может хранить настройки в нестандартной папке (например `AppData\Local\Claude-Data\…`): установщик её находит; если нет, откройте файл через Edit Config и добавьте блок `mcpServers` вручную |
| Работает в Claude Code, но не в Desktop | тот же вопрос: сервер должен быть прописан в `claude_desktop_config.json` |
| Установщик пишет, что это не пакет | скачан «Source code», а нужен `kerio-mcp-installer.zip` из Assets |
| Не удаляется папка при удалении | закройте Claude полностью (трей → Выход) и запустите `uninstall.bat` ещё раз или удалите папку вручную |

Проверка и отладка: `npm run inspect` (MCP Inspector).

## Ограничения

- Нет вложений в календарных событиях, контактов, задач и заметок, удаления папок (API не принимает известные параметры).
- Письма отправляются обычным текстом (без HTML-оформления).
- **Не проверено на реальном сервере:** рассылка приглашений участникам, ответ на приглашение и отмена собрания с
  участниками (написаны по описанию API Kerio). События без участников проверены вживую.
- Установщик проверен только в логике на Node.js; сам `install.bat` и скачивание `node.exe` на разных версиях Windows
  могут вести себя по-разному. Нашли проблему — откройте [issue](../../issues).
- Работа во вкладке Cowork приложения Claude Desktop зависит от того, как Cowork подключает локальные серверы; не гарантируется.

## Для разработчиков

```bash
npm test                         # тесты (Jest)
npm run inspect                  # MCP Inspector
installer/build.sh [хост]        # собрать dist/kerio-mcp-installer.zip (нужны Node.js и zip)
```

**Выпуск версии.** Тесты запускаются на каждый коммит (Actions → Tests). Чтобы выпустить установщик: Actions →
**Release installer** → Run workflow, указать тег вида `v1.0.2` (либо создать релиз на странице Releases). Workflow сам
прогонит тесты, соберёт архив и прикрепит его к релизу. Переменная репозитория `KERIO_DEFAULT_HOST` вшивает адрес сервера
в пакет, чтобы людей не спрашивали о нём: **задавайте её только в приватном репозитории**, в публичном архив виден всем.

**Устройство:**

- `server.js` — запуск stdio-сервера MCP.
- `src/kerio-client.js` — клиент API: вход при первом запросе, повторный вход при «Session expired», повторы при сетевых
  обрывах, загрузка и скачивание файлов, перевод HTML в текст.
- `src/tools.js`, `src/calendar-tools.js` — описание инструментов; `src/calendar.js`, `src/dates.js` — календарь и даты.
- `src/files.js` — папка файлов: проверка путей, безопасные имена, лимиты. `src/config.js` — чтение `config.json`.
- `installer/` — установщик для Windows (`install.bat`, `setup.js`, `uninstall.bat`, `get-node.ps1`, `build.sh`).

**Особенности API Kerio** (HTTPS JSON-RPC `/webmail/api/jsonrpc/`, справка: manuals.gfi.com → Client API):

- Фильтры по `isSeen`/`isFlagged` сервер принимает, но игнорирует: непрочитанные отбираются на стороне клиента.
- Перенос письма: `Mails.set` с `folderId`. Удаление насовсем: `Mails.remove` с `ids`. Отправка: черновик
  (`Mails.create`), затем `Mails.set` с `send: true` и полем `from`.
- Даты календаря: `20261030T150000+0300` (местное время ящика) или `20261031` для событий на весь день; сервер
  **игнорирует смещение во входящих датах**, поэтому даты отправляются в часовом поясе ящика. У события на весь день конец —
  следующий день.
- События: `Events.create/set/getById/remove`; список за период — `Occurrences.get` с условиями на `start` и `end`; одно
  повторение — `Occurrences.set/remove` с `modification`; ответ на приглашение — `Occurrences.setPartStatus`; приглашения —
  `Events.getEventUpdateList`; занятость — `FreeBusy.get` (для адресов без календаря ответ «NotAvailable» на весь период).
- Загрузка файла: `POST /webmail/api/jsonrpc/upload/` (multipart, поле `file`, заголовки `X-Token` и cookie), ответ
  `result.fileUpload.id` (живёт около часа) передаётся в `attachments[].id` при `Mails.create`. Скачивание: адрес из поля
  `url` вложения.

# Безопасность

## Как сообщить об уязвимости

Пожалуйста, **не создавайте публичный issue** для вопросов безопасности. Напишите через
[Security advisories](../../security/advisories/new) этого репозитория (личное сообщение мейнтейнеру).
Укажите версию, шаги воспроизведения и возможные последствия.

## Что важно знать пользователям

- Пароль от почты хранится локально: в `config.json` в папке установки (права только у вашей учётной записи Windows)
  либо в `.env`/переменных окружения. Он отправляется только на ваш сервер Kerio по HTTPS.
- Письма — недоверенный текст. Сервер помечает его как данные и удаляет скрытые элементы HTML, но решение об
  отправке писем, приглашений и файлов остаётся за вами. Файлы читаются и пишутся только в одной выбранной папке.
- Установщик не подписан цифровой подписью. Проверяйте, что скачиваете `kerio-mcp-installer.zip` со страницы Releases
  этого репозитория.

## Поддерживаемые версии

Исправления выпускаются для последней версии.

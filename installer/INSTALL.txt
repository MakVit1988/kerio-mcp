Подключение почты Kerio к Claude (Claude Desktop и Claude Code)
================================================================

Что нужно: Windows 10 или 11, интернет, ваша почта и пароль.
Node.js ставить не нужно: установщик сам возьмёт всё необходимое.

Установка
---------
1. Распакуйте архив целиком (правой кнопкой -> "Извлечь все"). Не запускайте файл из архива.
2. Дважды щёлкните install.bat.
   Если Windows пишет "Защитили ваш компьютер" - нажмите "Подробнее" -> "Выполнить в любом случае".
3. Ответьте на вопросы:
   - ваша почта (например, ivan@example.com);
   - пароль (при вводе символы не показываются);
   - папка для установки (можно просто нажать Enter);
   - папка для файлов: сюда скачиваются вложения писем, отсюда берутся файлы, которые нужно отправить.
4. Дождитесь слов "Готово".
5. Полностью закройте Claude Desktop (в том числе значок в трее) и откройте снова.
   Для Claude Code достаточно открыть новую сессию командой claude.

Как пользоваться
----------------
Пишите Claude обычными словами:
  - "покажи непрочитанные письма"
  - "найди письма от Иванова про счёт"
  - "скачай вложения из последнего письма от Иванова"
  - "отправь письмо на ivan@example.com с темой ... и приложи файл КП.pdf"
    (файл должен лежать в папке для файлов)

Claude отправляет письма от вашего имени. Просите показывать текст перед отправкой.

Если нужно обновить пароль или переустановить, просто запустите install.bat ещё раз.

Удаление
--------
Запустите uninstall.bat из папки, куда установили программу. Папка с вашими файлами не удаляется.

Безопасность
------------
Пароль хранится только в файле config.json в папке установки, доступ к нему есть только у вашей
учётной записи Windows. Claude может читать и отправлять только файлы из выбранной папки для файлов.
